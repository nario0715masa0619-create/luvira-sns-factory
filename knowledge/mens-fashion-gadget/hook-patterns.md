# Hook Patterns: Mens Fashion Gadget

## Purpose

40代ファッション×ガジェットジャンルで効いた/効かなかった hook の傾向を蓄積する。

## Current Status

Cold Start 中のため、confirmed pattern はまだない。

## Candidate Patterns / Early Notes

仮説レベルの hook 候補:

- 「40代男性の〜、見直すと仕事の印象変わる」型
  - OPS-002 で使用。late measurement で impressions=149。reach には届いた可能性があるが、engagement は 0。
  - hook 単体では反応を保証しない。1投稿だけでこの hook を winning / losing と断定しない。

- 「40代になって、高い靴よりちゃんと手入れしてる靴の方が大事だと気づいた」型
  - OPS-004 で使用。H002 靴の手入れ用。OPS-002 の hook 構造を維持しつつ、テーマだけを変更。
  - Distribution Learning Run では、別 content angle でも同一 hook 構造で Distribution を確保できるかを検証。
  - ハッシュタグは OPS-002 と同じ2タグ構成（Target Tag `#40代ファッション` 固定 + Content Angle Tag `#靴の手入れ`）を維持。

- 「40代、〜を整えたら自信が出てきた」型
  - OPS-003 の最終候補で使用。効果は未検証。

- 「40代、〜より先に〜を整えた方が変わる」型
  - 比較フック。未テスト。

- 「40代、服を買う前にやるべきこと」型
  - 命令的すぎる可能性あり。未テスト。

## Update Rules

- 複数 run の分析後に傾向を出す。
- 1投稿だけで hook の勝敗を決めない。
- 人間承認後に更新する。
