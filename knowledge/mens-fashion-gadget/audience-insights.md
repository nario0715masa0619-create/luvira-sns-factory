# Audience Insights: Mens Fashion Gadget

## Purpose

40代男性読者の反応傾向やインサイトを蓄積する。
Cold Start 中は仮説が中心。metrics 確認後に更新していく。

## Current Assumptions

- 40代男性は「若作り」より「清潔感」に反応しやすい。
- 高級品訴求より「無理なく整える」に反応しやすい。
- 仕事・第一印象・信頼感と結びつく投稿は相性が良い可能性がある。
- バッグの中身、靴、財布、小物など具体物があると保存されやすい可能性がある。
- 自慢っぽい投稿は避けるべき。
- 実体験風にする場合は実際の体験に寄せる必要がある。
- 押し付けがましくない同年代の友達口調が受け入れられやすい。
- 「3つの具体例」形式は保存しやすいが、連投すると陳腐化する。

## Confirmed Insights

まだ確定していないが、以下は仮説として支持される可能性がある:

- 40代男性×ファッション×ガジェットの方向性は、表示獲得の面で機能しうる。
- corporate-to-personal / genre correction の方向性は、1投稿のデータではあるが否定されない。

## Rejected / Weak Assumptions

- 「3つの具体例 + 価値転換 + CTA」構造だけで自動的に反応が取れる → 弱い可能性。
  - OPS-002 では表示は取れたが反応は0。
- 「みんなの〜、何が必須？」型のCTAが反応を誘発する → OPS-002 では機能しなかった。ただし OPS-004 では Distribution 比較のため同一形式を維持。CTA効果は Engagement Learning Phase で検証。

## Early Signals

- バッグの中身・画像なし・テキストのみ投稿では、今回 engagement は発生しなかった。
- text-only の靴の手入れ投稿は今回ほとんど配信されなかった（impressions=9）。
- 視覚変化が重要なテーマは画像なしだと弱い可能性がある。
- 40代ファッション×ガジェットで反応を取るには、より具体的な悩み・実物感・ビフォーアフターが必要かもしれない。
- 清潔感テーマは「靴単体」より「爪・髪・香り」など日常の自己管理寄りの方が検証価値ありかもしれない。
- ビジネス文脈に寄せた第一印象テーマも次の検証候補。
- 画像ありなら保存・反応が変わる可能性がある。
