# CTA Patterns: Mens Fashion Gadget

## Purpose

40代ファッション×ガジェットジャンルで効いた/効かなかった CTA の傾向を蓄積する。

## Current Status

Cold Start 中のため、confirmed pattern はまだない。

## Candidate Patterns / Early Notes

仮説レベルの CTA 候補:

- 「みんなの〜、何が必須？」型
  - OPS-002 で使用。impressions は取れたが likes/replies/bookmarks=0。
  - OPS-004 でも同一形式を使用。impressions=9、engagement=0。
  - 回答コストが高く、反応を誘発できなかった可能性。
  - Distribution Learning Run では CTA を比較変数とせず、content_angle の影響を測定。engagement 効果は別フェーズで検証。
  - 1投稿だけでこの CTA を reject しないが、類似 CTA の連続使用は避ける。

- 「みんなの〜、何？」型
  - 汎用的な問いかけ。OPS-003 で使用。効果は未検証。

- 「40代の〜、何から整えた？」型
  - 経験共有を促す。未テスト。

- 「意外と効く〜、あったら教えて」型
  - 情報収集型。未テスト。

- 「〜した人、いる？」型
  - 共感型。未テスト。

## Update Rules

- 複数 run の分析後に傾向を出す。
- reply_rate / bookmark_rate と紐づけて評価する。
- 人間承認後に更新する。
