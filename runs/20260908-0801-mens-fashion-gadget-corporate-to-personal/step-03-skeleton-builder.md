## Skeleton Pattern

### Skeleton Name

small-care-habit-beats-expensive-purchase

### Structure

```
[HOOK]: Personal realization in 40s
  → [THEME]: Small shoe care habit is enough
    → [LIST]: 3 concrete, low-effort care examples
      → [INSIGHT]: Maintenance matters more than luxury
        → [CTA]: Low-cost empathy question
```

### Section-by-Section Description

1. **Hook** (1 sentence)
   - Start with a personal realization.
   - Example: "40代になって、高い靴よりちゃんと手入れしてる靴の方が大事だと気づいた。"

2. **Theme** (1 sentence)
   - State the main idea: shoe care is a small weekly habit.
   - Example: "週1回の小さな手入れだけで、見た目がだいぶ変わる。"

3. **List** (3 items, each with brief parenthetical note)
   - Choose 3 from: brush dust, apply cream, dry wipe after rain, use shoe trees, quick polish before important meetings.
   - Keep each item short and practical.

4. **Insight** (1 sentence)
   - Reinforce the value shift from expensive shoes to well-maintained shoes.
   - Example: "高い靴じゃなくて、手入れが行き届いてるかどうか。"

5. **CTA** (1 question)
   - Invite reply or shared experience with low response cost.
   - Example: "靴磨き、ちゃんとやってる人どれくらいいる？"

### Skeleton Variations

- **Variation A**: Focus on "rain day care" (seasonal angle)
- **Variation B**: Focus on "before important meeting" (business angle)
- **Variation C**: Focus on "weekend 10-minute routine" (habit angle)

### Constraints

- Maximum 200 characters for X.
- Use at most 2 hashtags.
- CTA must invite reply/discussion, not follow/save.
- account_type: personal; source_account_type: corporate.
- Do not copy original post text.
- Do not invent personal experience.
- Avoid lecturing tone.

## Framework Summary

| Element | Purpose | Length |
|---------|---------|--------|
| Hook | Relate and promise | 1 sentence |
| Theme | Define the angle | 1 sentence |
| List | Provide practical value | 3 short items |
| Insight | Shift value perception | 1 sentence |
| CTA | Drive engagement | 1 question |
