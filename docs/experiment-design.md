# Experiment Design

## Experiment 001

### Claude SNS Engine vs Kimi K2.7 Low-Cost SNS Factory

## 目的

Claude + Claude Code 版の SNS 生成システムと、OpenCode Go + Kimi K2.7 Code 版の低コスト SNS Factory を、同条件で比較し、どちらが 24 時間後のインプレッション数で優位かを検証する。

## 比較対象

| 項目 | Team A | Team B |
|------|--------|--------|
| 名称 | Claude SNS Engine | Kimi K2.7 Low-Cost SNS Factory |
| モデル | Claude + Claude Code | OpenCode Go + Kimi K2.7 Code |
| 設計思想 | 既存の Claude 版設計 | 構造転用・低コスト量産 |

## 投稿数

- Team A: 5 本
- Team B: 5 本
- 合計: 10 本

## 投稿期間

- 5 日間

## 投稿頻度

- 1 日 2 本
- Team A と Team B を交互に投稿する

## 投稿条件

| 条件 | 詳細 |
|------|------|
| アカウント | 同じアカウントを使用 |
| ジャンル | 同じジャンルに限定 |
| 時間帯 | 近い時間帯に投稿 |
| 画像条件 | 統一（有無・スタイル） |
| リンク | なし |
| ハッシュタグ | 最大 2 つ |
| 追加拡散 | 投稿後の追加拡散なし |

## 測定指標

### Primary KPI
- 平均 24h インプレッション数

### Secondary KPI
- 最大 24h インプレッション数
- いいね数
- リプ数
- プロフィール遷移数
- 生成コスト
- 人間修正時間
- 人間採用率

## 勝敗判定

1. **平均 24h インプレッション数が高いチームを勝者とする。**
2. 平均が同程度の場合、最大 24h インプレッション数も参考指標とする。
3. それも同程度の場合、生成コストと人間修正時間が少ない方を勝者とする。

## 実験後の分析

- 勝者の構造・フック・感情導線を分析する。
- 敗者の改善点を列挙する。
- 次回実験の仮説を立てる。

## 注意事項

- 実験期間中は、Claude 版の内部設計を Kimi 版に持ち込まない。
- 両チームとも人間承認を経て投稿する。
- 投稿後の追加拡散は一切行わない。
- 24 時間後の数値は客観的に記録する。
