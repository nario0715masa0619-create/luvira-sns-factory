# Evaluation Rule

## Primary KPI

### 投稿から 24 時間後のインプレッション数

- 勝敗はこれで決める。
- 投稿時刻を正確に記録し、24 時間後（±30 分）に数値を取得する。
- 複数投稿の比較では、平均 24h インプレッション数を基本とする。

## Secondary KPI

| KPI | 説明 | 測定方法 |
|-----|------|----------|
| 人間採用率 | 生成案のうち、人間が承認して投稿した割合 | 承認数 / 提案数 |
| 人間修正時間 | 提案から承認までの時間 | タイムスタンプ記録 |
| 生成コスト | 1 案あたりの推論コスト | モデルのトークン単価 × 使用量 |
| いいね数 | 投稿後のいいね数 | プラットフォームの数値 |
| リプ数 | 投稿後のリプライ数 | プラットフォームの数値 |
| プロフィール遷移 | プロフィールクリック数 | プラットフォームの数値 |
| パクリ感の少なさ | 元バズ投稿との類似度の主観評価 | 1-5 の評価（5 が最もオリジナル） |
| ブランド適合度 | クライアントブランドとの整合性 | 1-5 の評価（5 が最も適合） |
| account_type 適合性 | `personal` / `corporate` の投稿先アカウント種別に適しているか | 1-5 の評価（5 が最も適合） |
| 別ジャンルへの再現性 | 同じ構造が他業種でも使えるか | 1-5 の評価 |

## account_type 別の評価観点

### personal

- **共感度**: ターゲットの日常課題・本音に寄り添っているか
- **リプ誘発力**: 経験募集・問いかけ・議論を促す CTA になっているか
- **本音感**: 機械的ではなく、人間らしい体験談トーンか
- **虚偽体験の有無**: 捏造された実体験・実績がないか
- **類似性**: 元投稿のフレーズを流用していないか

### corporate

- **信頼性**: 客観的・安心感のある表現になっているか
- **保存性**: ノウハウ・チェックリスト・資料として保存されやすいか
- **問い合わせ導線**: 無料相談・資料請求・チェックリストなどの CTA になっているか
- **ブランド毀損リスク**: 攻撃的・煽情的・過度な保証表現がないか
- **一人称体験談の不自然さ**: 「僕も」「私も」などの個人体験調が使われていないか
- **実務チェック項目の具体性**: セキュリティ診断等の場合、古い権限・未使用アカウント・API キー・外部連携など、実務で確認すべき項目が具体的に示されているか
- **根拠不明表現の少なさ**: 「当社の調査では」「導入実績では」「多くの企業で」など、根拠のない調査風・実績風表現が含まれていないか

## 比較実験の評価

### Claude SNS Engine vs Kimi K2.7 Low-Cost SNS Factory

詳細は `docs/experiment-design.md` を参照。

#### 勝者条件

1. **平均 24h インプレッション数が高いチームを勝者とする。**
2. 平均が同程度の場合、最大 24h インプレッション数を参考指標とする。
3. それも同程度の場合、生成コストと人間修正時間が少ない方を勝者とする。

## 継続改善ルール

- 24 時間後の数値を必ず記録する。
- 上位案と下位案の差分を分析する。
- 構造・フック・感情分類のどこが効いたかを検証する。
- 次回のプロンプト改善に反映する。

## 測定時の注意

- 投稿後の追加拡散（リポスト、宣伝等）は行わない。
- 比較対象は同じアカウント・同じジャンル・近い時間帯とする。
- 画像条件、ハッシュタグ数、リンク有無を統一する。
- インプレッション数は各プラットフォームの公式数値を使用する。
