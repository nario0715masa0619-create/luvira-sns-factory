# Product Definition

## Product Vision

低コスト AI モデル（Kimi K2.7 Code）を中心に、バズ投稿の「構造転用」と「感情導線の再設計」で、クライアント商材に最適化された SNS 投稿を再現性良く生成する。

最終的には、人間が承認するだけで投稿できる品質の候補を、安価に大量に生産し、24 時間後のインプレッション数で勝敗を測る。

## Problem

- AI に 0→1 で投稿を書かせると、パクリ感が強く、ブランドに合わない、事実誤認や誇大表現が混ざる。
- 高コストモデルに依存すると、大量の案を試作できない。
- 人間が一から書くと再現性・スピードが落ちる。
- 何が伸びたのか（構造・感情・反応設計）を分析せずに生成すると、再現性がない。

## Target Users

- 自社 SNS 運用を内製化したい中小企業・個人事業主
- 投稿数を増やしつつ品質を維持したいマーケター
- クライアントの業種・商材に合わせた投稿を短納期で出したいディレクター
- 既存 Claude 版と比較しながら、低コストモデルの可能性を検証したい Luvira 内部チーム

## Core Value

1. **再現性**
   バズ投稿の構造を分析し、それを別商材に置換するので、同じロジックで繰り返し使える。

2. **低コスト**
   Kimi K2.7 Code を初期主力とし、大量のバリエーション生成を安価に行う。

3. **安全性**
   パクリ感・誇大広告・事実誤認・炎上リスクを多段階でチェックする。

4. **人間中心**
   自動投稿はせず、人間が最終承認する。

5. **数字評価**
   勝敗は 24 時間後のインプレッション数で決める。

## Non-Goals

- 完全自動投稿システムの構築
- 画像・動画の自動生成
- n8n や API 連携による自動化
- 既存 Claude 版の単純な置き換え（まずは並走・比較検証で勝敗を測る）
- 炎上やバズを意図的に狙う投稿設計
- クライアント機密データや顧客情報を学習・保持する仕組み

## Success Metrics

### Primary KPI
- 投稿から 24 時間後のインプレッション数

### Secondary KPI
- 人間採用率（生成案が承認される割合）
- 人間修正時間（承認までにかかる時間）
- 生成コスト（1 案あたりの推論コスト）
- いいね数・リプ数・プロフィール遷移数
- パクリ感の少なさ（主観評価 1-5）
- ブランド適合度（主観評価 1-5）
- 別ジャンルへの再現性（同じ構造が他業種でも使えるか）

## MVP Scope

- ドキュメント設計とプロンプト設計の完成
- 10 段階の AI 役割チェーンの定義
- 手動でプロンプトを順に実行し、出力を検証できる状態
- 入出力スキーマの定義
- 実験設計（Claude 版 vs Kimi K2.7 版）の策定
- 安全性ポリシーの策定

## Later Scope

- ローカル実行スクリプト（Python / Node）によるプロンプトチェーンの自動化
- 入出力の JSON / CSV 化
- 軽量な Web UI または CLI ツール
- 実験結果の記録・分析ダッシュボード
- 構造テンプレートの蓄積と検索
- 必要に応じて Qwen / GLM / K3 など他モデルの追加比較
- n8n 等を使った半自動化（ただし投稿承認は人間が行う）
