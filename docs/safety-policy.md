# Safety Policy

## 元バズ投稿の取り扱い

### 文言コピー禁止
- 元バズ投稿の文章をそのまま流用しない。
- 一部のフレーズを切り貼りすることも禁止。

### 類似しすぎる投稿の禁止
- 元投稿の固有名詞、独自の表現、キャッチコピーを転用しない。
- 構造の類似は許可するが、読者が「パクリだ」と感じるレベルは禁止。

## account_type 別の安全基準

### 前提
- すべての投稿は `account_type`（`personal` / `corporate`）を Step 0 で確定させる。
- `account_type` 未指定の場合は、生成・投稿いずれも進めない。

### personal

- 虚偽の実体験・確認不能な実績・捏造された失敗談を禁止する。
- 「僕も」「私も」などの一人称体験調は許容するが、内容は事実または一般論に基づくものにする。
- 過度な不安煽り・攻撃的表現・特定集団を貶める表現を禁止する。
- 「個人だから言える本音感」は許容するが、事実誤認や法務リスクを伴う表現は避ける。

### corporate

- 「僕も」「私も」などの一人称体験談を原則禁止する。
- 保証表現（「絶対」「完全」「100%」「漏洩しない」等）をより厳しく制限する。
- 誇大広告・過度な煽り・ブランド毀損リスクのある表現を厳格に禁止する。
- 客観的データ・一般論・企業としての見解に基づいた表現を基本とする。
- 比較広告・競合言及は、客観的データと明確な根拠を必ず添える。
- 根拠のない調査風・実績風表現（「当社の調査では」「導入実績では」「多くの企業で」等）は使用しない。確認できるデータや出典がある場合のみ、明示的に出典を示して使用可能。

## 表現上の禁止事項

### 誇大広告禁止
- 「最安値」「絶対」「誰でも」「完璧」など、根拠のない断定表現を使わない。
- 効果を保証する表現は、客観的データがある場合のみ使用可能。

### 事実確認できない断定禁止
- 「〜である」「〜する」など、検証できない断定を避ける。
- 不明な情報は「〜と考えられる」「〜の可能性がある」などにする。
- 法人投稿では、「当社の調査では」「導入実績では」「多くの企業で」など、根拠が不明確な調査風・実績風表現を特に厳しく制限する。

### 炎上誘発表現の扱い
- 特定の人物・団体・業界を攻撃する表現を使わない。
- 意見が分かれる話題については、中立的な立場を保つ。
- 読者を煽るような表現（「あなたはどっち派？」など）は慎重に扱う。

### 法務リスクの扱い
- 医療・健康・金融・投資・景品表示法に関わる表現は特に慎重に扱う。
- 比較広告は、客観的データと根拠を明記する。
- 第三者の著作物・商標・肖像権を侵害しない。

## 情報セキュリティ

### 機密情報の投入禁止
- クライアント機密情報をプロンプトに入れない。
- API キー、`.env`、顧客データを Repository やログに残さない。
- 個人情報や顧客リストを扱わない。

## 運用ルール

### 自動投稿禁止
- AI やスクリプトによる自動投稿は行わない。
- 必ず人間が手動で投稿する。

### 人間承認必須
- 最終的な投稿は、必ず人間が内容を確認・承認してから公開する。
- Final Packager の承認チェック欄を必ず通す。

## 違反時の対応

- 明らかに違反する案は即座に棄却する。
- グレーゾーンの表現は、人間が判断するまで公開しない。
- 過去の違反例を学習資料として蓄積する。

## 適用法規の意識

- 景品表示法
- 医薬品医療機器等法（医療・健康関連）
- 金融商品取引法（金融・投資関連）
- 著作権法
- 商標法
- 個人情報保護法
