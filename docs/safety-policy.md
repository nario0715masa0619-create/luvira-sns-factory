# Safety Policy

## 元バズ投稿の取り扱い

### 文言コピー禁止
- 元バズ投稿の文章をそのまま流用しない。
- 一部のフレーズを切り貼りすることも禁止。

### 類似しすぎる投稿の禁止
- 元投稿の固有名詞、独自の表現、キャッチコピーを転用しない。
- 構造の類似は許可するが、読者が「パクリだ」と感じるレベルは禁止。

## 表現上の禁止事項

### 誇大広告禁止
- 「最安値」「絶対」「誰でも」「完璧」など、根拠のない断定表現を使わない。
- 効果を保証する表現は、客観的データがある場合のみ使用可能。

### 事実確認できない断定禁止
- 「〜である」「〜する」など、検証できない断定を避ける。
- 不明な情報は「〜と考えられる」「〜の可能性がある」などにする。

### 炎上誘発表現の扱い
- 特定の人物・団体・業界を攻撃する表現を使わない。
- 意見が分かれる話題については、中立的な立場を保つ。
- 読者を煽るような表現（「あなたはどっち派？」など）は慎重に扱う。

### 法務リスクの扱い
- 医療・健康・金融・投資・景品表示法に関わる表現は特に慎重に扱う。
- 比較広告は、客観的データと根拠を明記する。
- 第三者の著作物・商標・肖像権を侵害しない。

## 情報セキュリティ

### 機密情報の投入禁止
- クライアント機密情報をプロンプトに入れない。
- API キー、`.env`、顧客データを Repository やログに残さない。
- 個人情報や顧客リストを扱わない。

## 運用ルール

### 自動投稿禁止
- AI やスクリプトによる自動投稿は行わない。
- 必ず人間が手動で投稿する。

### 人間承認必須
- 最終的な投稿は、必ず人間が内容を確認・承認してから公開する。
- Final Packager の承認チェック欄を必ず通す。

## 違反時の対応

- 明らかに違反する案は即座に棄却する。
- グレーゾーンの表現は、人間が判断するまで公開しない。
- 過去の違反例を学習資料として蓄積する。

## 適用法規の意識

- 景品表示法
- 医薬品医療機器等法（医療・健康関連）
- 金融商品取引法（金融・投資関連）
- 著作権法
- 商標法
- 個人情報保護法
