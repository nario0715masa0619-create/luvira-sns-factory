## 転用先情報

### account_type

- `personal`
- 投稿先アカウントの種別

### source_account_type

- `corporate`
- 元投稿アカウントの種別
- `source_account_type` と `account_type` が異なるため、文体・一人称・CTA を必ず調整する

### 転用先業種

- IT / システム開発

### 商材

- AI 活用型短納期システム開発

### ターゲット

- 中小企業の IT 責任者・エンジニア・技術発信者・開発マネージャー。日常業務が多忙で、AI活用のスピード感に飲まれがち。

### 投稿目的

- AI 活用型短納期システム開発サービスの認知獲得と、個人アカウントらしい議論・経験共有の場を作ること。

### desired_cta_style

- `reply` / `discussion` / `experience_sharing`
- `personal` の場合はリプ・共感・経験募集・問いかけを優先

### allowed_persona_expression

- `僕 / 私 / 自分 / 主語省略`
- ただし、架空の本人実体験を捏造しない。
- 「僕も経験しました」「私も失敗しました」「自分もやらかしました」などは禁止。

### risk_tolerance

- `balanced`

### NG 表現

- 「最安値」「絶対」「誰でも」「完全」「100%」「一切」「漏洩しない」
- 競合他社の否定的な言及
- 架空の本人実体験（「僕も半年前に…」「私もやらかした…」等）
- 本人経験・他社経験・伝聞を匂わせる表現（「個人的な話だけど」「知り合いの会社で」「友達の現場で」「前に見た現場で」「ある会社で」「以前相談を受けた」「実際にあった」「現場でよくある」等）
- 虚偽の実績・効果保証
- 押し売り・煽り・断定

### 口調

- 親しみやすい個人トーン。やわらかく、共感を重視。押し売り感を出さない。
- 本音・疑問・観察・仮説を投げかける。ただし、確認不能な体験談は使わない。

### 文字数条件

- X 用。本文 200 文字以内。ハッシュタグは最大 2 つ。

### 画像あり/なし

- [x] なし

### ハッシュタグ条件

- #AI活用 #システム開発
- 最大 2 つまで。

### 備考

- 医療効果・金融効果を示唆しない。
- 競合比較はしない。
- 商品の価格や割引は今回言及しない。
- 具体の顧客事例や数値は入れない。
- 機密情報を含めない。
- 転用後は「気づき → 実務あるある → 問いかけ → 軽い商材接続 → 返信/経験共有CTA」の構造を目指す。
- 法人っぽい無機質な告知文・資料請求CTAは残さない。
- 第2商材らしい論点（要件整理、スコープ管理、AIコード生成レビュー体制、技術負債、MVPと本開発の切り分け等）を自然に扱う。
